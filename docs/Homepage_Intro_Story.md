# Homepage research introduction

The introduction retains the research wording and overview figure from the previous remote main version, `f0adf89`, with typography and paragraph structure optimized for reading. The order is motivation, evaluation framework, overview figure, and benchmark scope. All research prose is visible without expansion. The introductory grid, experimental photographs, chapter video and animation are no longer mounted on the homepage. Shared white page backgrounds remain in effect.

`scripts/intro-story.html` is the canonical restored markup. Run `python3 scripts/build_intro_story.py` to refresh only the introduction in `index.html`; the full site builder uses the same renderer. The renderer's block markers allow future focused updates. The current typography lives in `scripts/intro-typography.css`: Helvetica, 21px desktop body text (18px on mobile), 1.7 leading, and a full-width reading column aligned with the surrounding media. The first sentence is a restrained 23px lead. The three evaluation views are a semantic definition list, with labels beside descriptions on desktop and above them on narrow phones. Longer prose is split at sentence boundaries. The overview and text share the same width and left edge. The previous story CSS/JS and media remain on disk but are not loaded by this introduction.

Run `node scripts/test_intro_story.cjs` using the existing Playwright environment to verify original copy, figure, reading order and responsive layout.
