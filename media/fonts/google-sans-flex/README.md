# Google Sans Flex

Unmodified variable WOFF2 subsets (latin, latin-ext, symbols) as served by Google Fonts
(`css2?family=Google+Sans+Flex:opsz,wght@6..144,1..1000`, v26). Axes: opsz 6–144, wght 1–1000.

Source: https://github.com/google/fonts/tree/main/ofl/googlesansflex
License: SIL Open Font License 1.1; see OFL.txt. Retrieved 2026-11-05.

Chosen to match the type of robodojo-benchmark.com. Loaded by media/typography.css,
which media/site-shell.css imports on every page.
