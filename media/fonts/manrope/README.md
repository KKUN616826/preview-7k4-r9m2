# Manrope

Unmodified variable font from the Google Fonts repository. Weight range: 200–800.

Source: https://github.com/google/fonts/tree/main/ofl/manrope
Font file: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/Manrope%5Bwght%5D.ttf
License: SIL Open Font License 1.1; see OFL.txt. Retrieved 2026-11-04.
