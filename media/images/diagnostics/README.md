# Diagnostic teaser artwork

`lunar-silver.webp` is generated lunar background artwork for the Home preview.
It contains no report, labels or diagram; these remain native HTML and SVG.

Generated with the built-in ImageGen tool on 2026-11-07, based on the approved
carbon lunar concept and the user's lighter reference. The final direction was
a neutral graphite-to-pearl gradient, broad simplified lunar relief, little
surface texture, no buildings or sky decoration, and no text. Compressed from
the generated PNG to WebP for the website. It is concept artwork, not a lunar
mission photograph.

The report is an illustrative synthetic profile. It must not imply real model
measurements or a released diagnosis service.
