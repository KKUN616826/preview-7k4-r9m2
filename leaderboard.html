Context behind the numbers

Reading the leaderboard

Understand the metrics, coverage, and limits of the current result snapshot.

Metrics

Score reports task performance on a 0–100 scale. Success reports the final task success rate as a percentage. These are separate measurements, not interchangeable scores.

“—” means unreported. A measured zero remains 0.00 or 0.0.

Evaluation setting

The expanded catalog defines 30 tasks across three suites and three difficulty levels. The added tasks are not included in this result snapshot. This page preserves all-level Score and Success values from the supplied Table 6.

Difficulty-specific results and trial-level statistics are not included in this snapshot.

Comparability

Model paradigms differ in training conditions and action interfaces. Exact checkpoints, execution assistance, observation permissions and evaluation budgets need to be read alongside any comparison.

Detailed run configurations are not bundled with this result snapshot.

Sources and evidence

Values were preserved from the existing project leaderboard, which identifies the supplied Table 6 as its source. No new measurements or verification claims are added.

Linked videos are model-family demonstrations and are not scored evaluation runs.
